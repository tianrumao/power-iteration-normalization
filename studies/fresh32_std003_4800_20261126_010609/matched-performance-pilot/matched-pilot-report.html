训练设置和检查点如何选择？

模型、数据生成规则、输入编码和归一化实现沿用原实验。当前 normalizer 是前 3 个 block 后的 token 列向量 L2 单位化。两组共享初始化、数据和批次计划；按条件调整学习率：111 为 0.001，000 为 0.0005，最多 12,800 步，临近目标时每 50 步保存权重。

先在独立试跑中依次检查预先规定的共同水平 78%、75%，每组候选需处于目标 ±0.5 个百分点。选定所有检查点后，才打开独立确认验证集，并要求每对差距 ≤1 个百分点。此次共同水平为 75%，两对确认集差距为 0.20、0.59 个百分点。

检查到的完整性证据

  • 按 X 矩阵逐样本 SHA-256 检查，训练、选择验证、独立确认和测试之间未发现完全相同的矩阵；各集合内部也未发现完全重复矩阵。
  • 每个冻结模型在前 128 个测试样本的输入及全部 4 层状态上，未发现非有限坐标。检查范围和数值尺度保存在 leakage-and-numerics.json。
  • 所有评分前后均验证模型文件哈希未变。没有根据测试分数重新选择检查点。
  • 这些检查支持“没有发现所检查的重复或数值异常”，不能证明不存在所有形式的过拟合或分布变化。
